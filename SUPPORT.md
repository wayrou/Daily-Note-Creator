# Koala Support Policy

## Supported platforms

- Windows 10 and later, 64-bit
- macOS versions supported by the bundled Electron release

Production distribution should use signed installed builds. Portable builds are intended for evaluation and troubleshooting and do not support automatic in-place updates.

## Release channels

- Stable: tagged production releases approved for organizational deployment
- Prerelease: alpha, beta, and release-candidate builds for testing

## Support request information

Include:

- Koala version
- Operating system version
- Installed or portable build
- Exact steps to reproduce
- Expected and actual results

Do not send production student information, therapy notes, exported PDFs, or backups unless a secure support process has been explicitly established.

## Backup responsibility

Organizations are responsible for backing up and retaining their exported records. Koala's local autosave is not a substitute for an organizational backup program.
