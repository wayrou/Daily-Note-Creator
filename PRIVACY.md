# Koala Privacy Overview

Koala is designed as a local-first application.

## Data stored on the device

- Notes and note organization
- Organization name and new-note defaults
- Therapy rules and recent field values
- Theme preference
- Imported organization license record

These values remain in Koala's local application storage until a user deletes them, restores a backup, or removes the application data.

## Data leaving the device

Koala does not include analytics or advertising. Data leaves the device only through an explicit user workflow:

- Exporting a PDF or JSON backup
- Using Mobile Session on the local network
- Checking GitHub Releases for application updates in an installed build

## Recommended organizational controls

- Use managed devices with full-disk encryption and individual staff accounts.
- Define retention and deletion rules for notes, PDFs, and backups.
- Store exported files only in approved locations.
- Treat JSON backups as sensitive records.
- Avoid student full names when initials satisfy the business need.
- Stop Mobile Session after use and use only trusted networks.

This overview is product documentation, not legal advice or a substitute for an organization's privacy notice or data-processing agreement.
