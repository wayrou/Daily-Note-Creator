    Suggested Words

    Koala can offer words you have already used as chips under a field. Turning this off hides the chips and stops collecting new ones; words already stored stay on this device.

    Organization

    Set the identity and defaults used when staff create a new note.

    Lesson Plan Lists

    Your own shortcuts for the lesson plan. Paste one entry per line — these are offered as suggestions in the editor and saved on this device only. Koala ships no curriculum content.

    Lesson Plan Pages

    The weekly plan prints in small type so that a full form still fits on one sheet. With this on, a box holding only a little prints larger to fill the space it has.

    Therapy Rules

    Set weekly therapist defaults by student initials and weekday. Matching notes fill only blank therapy fields.

    Local Data

    Koala stores notes and preferences on this device. Create a backup before moving devices or clearing records.
